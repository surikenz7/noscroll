# NoScroll

A userscript that turns instagram.com into Instagram without the endless scrolling. It runs in Safari on iPhone through the free **Userscripts** Safari extension (App Store).

- Home feed posts hidden, the stories tray stays
- Explore opens plain search instead of the grid
- Reels tab hidden, and swiping from one reel to the next is blocked
- DMs, notes, stories, profiles and settings untouched

Install page: https://surikenz7.github.io/noscroll/

## Updating
Change `noscroll.user.js`, bump `@version`, commit and push. Userscripts picks up the new version from `@updateURL`.

All Instagram-specific selectors and paths are in `CONFIG` at the top of the script.
