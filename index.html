NoScroll

Instagram without the feed. No home feed, Explore or Reels tab. Messages, stories, notes, reels friends send you and settings still work.

Install script

Set up on iPhone

  1. Install Userscripts (free) from the App Store, open it once and pick a folder when it asks.
  2. Settings → Apps → Safari → Extensions → Userscripts: turn it on and set instagram.com to “Allow”. Also allow this page (github.io), so it can install the script.
  3. In Safari, tap Install script above. Then tap the puzzle icon (or “aA”) in the address bar → Userscripts → Install.
  4. Open instagram.com/direct/inbox/ in Safari and log in. You should see a blue “NoScroll on” badge for a moment.
  5. Share → Add to Home Screen, and turn “Open as Web App” off. With it on, the icon opens without Safari and the script doesn't run.

What it does

  • Home: posts are hidden, only the stories bar at the top is left.
  • Explore: the button opens plain search (to find people), not the grid.
  • Reels tab: gone.
  • Reels from friends: they play, but swiping to the next one takes you back.

Test checklist

  • Instants: can you open, send and receive them?
  • Notes in messages: can you see and add them?
  • Posting a story
  • Message notifications
  • Home Screen icon opens with the “NoScroll on” badge
  • Home shows stories only, swiping to the next reel doesn't work
  • Does it feel smooth enough compared with the app?

Updates: open the Userscripts menu in Safari and check for updates. Nothing here sees your password, the script only changes how instagram.com looks in your own Safari.
