NoScroll

Instagram without the feed, using only Safari. Nothing to install: it's a bookmark you tap after Instagram opens.

Set up once

  1. Tap Copy bookmark code above.
  2. Bookmark this page: Share → Add Bookmark, save it in Favorites, name it NoScroll.
  3. Open Bookmarks → Edit → tap NoScroll. Delete the address, paste the copied code, tap Done. The address must start with javascript:
  4. Optional Home Screen icon: open instagram.com in Safari → Share → Add to Home Screen, with “Open as Web App” off. It has to open in Safari, because you need the address bar to tap the bookmark.

Every time

  1. Open instagram.com in Safari (or the Home Screen icon).
  2. Tap the address bar → tap NoScroll in Favorites. A blue “NoScroll on” badge appears.

It stays on while you use Instagram. If the page reloads (pull to refresh, or Safari reloads the tab later), tap it again.

What it does

  • Home: posts are hidden, only the stories bar at the top is left.
  • Explore: only the search bar is left, to find people.
  • Reels tab: gone.
  • Reels from friends: they play, but swiping to the next one takes you back.

Test checklist

  • Tapping NoScroll shows the blue badge (if not, tell me)
  • Instants: can you open, send and receive them?
  • Notes in messages: can you see and add them?
  • Posting a story
  • Message notifications
  • Home shows stories only, swiping to the next reel doesn't work
  • Does it feel smooth enough compared with the app?

The code only changes how instagram.com looks in your own Safari. It never sees your password. After an update, copy the code again and paste it into the bookmark.
